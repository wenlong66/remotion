# @remotion/whisper-webgpu<AvailableFrom v="4.0.518" />

Transcribe audio locally in the browser using timestamped Whisper models and WebGPU through [Transformers.js](https://huggingface.co/docs/transformers.js), and convert the result to [`@remotion/captions`](/docs/captions).

import {TableOfContents} from './table-of-contents';

## Installation

<Installation pkg="@remotion/whisper-webgpu @huggingface/transformers@4.2.0" />

`@huggingface/transformers` is a peer dependency. Remotion recommends and tests version `4.2.0` so that multiple browser-based AI workflows can share one Transformers.js runtime.

## Example

```ts twoslash title="transcribe.ts"
import {clearStaleModels, resampleTo16Khz, toCaptions, transcribe} from '@remotion/whisper-webgpu';

await clearStaleModels();

const file = new File([], 'audio.wav');
const channelWaveform = await resampleTo16Khz({file});

const transcription = await transcribe({
  channelWaveform,
  model: 'small.en',
  language: 'en',
});

const {captions} = toCaptions({whisperWebGpuOutput: transcription});
console.log(captions);
```

The model is downloaded on the first call and cached by the browser. Call [`loadWhisperModel()`](/docs/whisper-webgpu/load-whisper-model) first to display model download progress.

## Model downloads<AvailableFrom v="4.0.522" />

Model files are downloaded from `remotion.media`.

`@remotion/whisper-webgpu` temporarily sets `env.remoteHost` while loading a model and restores it afterwards. This keeps the shared Transformers.js runtime available to other AI workflows. If your site uses a Content Security Policy, allow `https://remotion.media` in `connect-src`.

Versions before 4.0.522 downloaded models from Hugging Face. After upgrading, the browser downloads a previously cached model once more because the download URL, and therefore its cache key, has changed. Call [`clearStaleModels()`](/docs/whisper-webgpu/clear-stale-models) to remove the old Hugging Face cache entries. With the default Transformers.js cache settings, subsequent loads use the new cached copy.
