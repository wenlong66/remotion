# getAvailableVideoMattingModels()<AvailableFrom v="4.0.523" />

Returns metadata for the models supported by [`separateVideoLayers()`](/docs/video-matting/separate-video-layers).

```ts twoslash title="models.ts"
import {getAvailableVideoMattingModels} from '@remotion/video-matting';

const models = getAvailableVideoMattingModels();
console.log(models);
```

| Name        | Purpose                     | Status                           |
| ----------- | --------------------------- | -------------------------------- |
| `modnet`    | People                      | Default                          |
| `ben2-base` | General foreground subjects | Experimental and higher-resource |

The [`modnet` model](https://huggingface.co/Xenova/modnet) is Apache-2.0 licensed. The [`ben2-base` model](https://huggingface.co/onnx-community/BEN2-ONNX) is the MIT-licensed BEN2 Base export.

The `modelId` values identify these upstream Hugging Face models for provenance. Runtime files are downloaded from immutable paths on `remotion.media` and are byte-identical to files from the pinned upstream revisions.

Each model contains these properties:

### name

The model name accepted by APIs in this package.

### modelId

The upstream Hugging Face model identifier. This is provenance metadata, not the runtime download location.

### purpose

A short description of the subjects the model is intended to separate.

### webGpuDownloadSize

The total size in bytes of all runtime files downloaded for WebGPU.
