# clearStaleVideoMattingModels()<AvailableFrom v="4.0.523" />

Removes cached model files that are no longer returned by [`getAvailableVideoMattingModels()`](/docs/video-matting/get-available-video-matting-models).

It also removes legacy entries for the pinned Hugging Face revisions that were used before models moved to `remotion.media`.

Call this function after upgrading `@remotion/video-matting` to remove files for models discontinued by a newer version.

Only known legacy video-matting entries are removed. Current files from `remotion.media` and cache entries used by unrelated Transformers.js workflows are preserved.

```ts twoslash title="clear-stale-models.ts"
import {clearStaleVideoMattingModels} from '@remotion/video-matting';

await clearStaleVideoMattingModels();
```

## Return value

A `Promise<void>` that resolves after stale model files have been removed.
