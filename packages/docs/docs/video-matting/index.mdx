# @remotion/video-matting<AvailableFrom v="4.0.523" />

Separate a video into an opaque base layer and a foreground layer with alpha, locally in the browser using WebGPU.

import {TableOfContents} from './table-of-contents';

## Installation

<Installation pkg="@remotion/video-matting @huggingface/transformers@4.2.0" />

`@huggingface/transformers` is a peer dependency. Install exactly version `4.2.0`.

## Example

```ts twoslash title="separate-video.ts"
import {separateVideoLayers} from '@remotion/video-matting';

const file = new File([], 'input.mp4');

const {base, foreground} = await separateVideoLayers({
  src: file,
});

const baseBlob = await base.getBlob();
const foregroundBlob = await foreground.getBlob();

await Promise.all([base.dispose(), foreground.dispose()]);
```

Call `dispose()` after retrieving the blobs to release package-owned temporary storage.

The model is downloaded on the first call and cached by the browser. Call [`loadVideoMattingModel()`](/docs/video-matting/load-video-matting-model) first to display download progress.

## Model hosting

Model files are downloaded from immutable paths on `remotion.media`. They are byte-identical mirrors of files from pinned upstream Hugging Face revisions. The public `modelId` metadata identifies the upstream source for provenance; it is not the download location.

## Layer order

The base is an opaque copy of the input video. The foreground contains the detected subject and transparent pixels everywhere else.

Stack the layers in this order:

1. Base
2. Inserted content, such as text or graphics
3. Foreground

The base intentionally still contains the subject. The foreground draws it over the inserted content, making the content appear behind the subject. Video matting does not reconstruct scenery hidden by the subject.

Audio is included in the base by default and omitted from the foreground, so stacking both layers plays it once.

## Requirements

WebGPU requires HTTPS in production or `localhost` during development. Use [`canUseVideoMatting()`](/docs/video-matting/can-use-video-matting) to check whether the selected model is supported.

If the page uses a strict Content Security Policy, add `https://remotion.media` to its `connect-src` directive, for example `connect-src 'self' https://remotion.media`.

The browser must also be able to decode the input video and encode VP9 with alpha through WebCodecs. [`separateVideoLayers()`](/docs/video-matting/separate-video-layers) checks these media capabilities for the selected input.
