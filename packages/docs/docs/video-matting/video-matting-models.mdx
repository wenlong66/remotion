# VIDEO_MATTING_MODELS<AvailableFrom v="4.0.523" />

A readonly array containing the model names supported by `@remotion/video-matting`.

```ts twoslash title="models.ts"
import {VIDEO_MATTING_MODELS} from '@remotion/video-matting';

console.log(VIDEO_MATTING_MODELS);
// ['modnet', 'ben2-base']
```

Use [`getAvailableVideoMattingModels()`](/docs/video-matting/get-available-video-matting-models) to retrieve model metadata such as purpose, download size, and whether a model is experimental.
